# 更新日志 / Changelog

## 未发布 / Unreleased

- 主图鉴保留 144 个精选作品。「全部」按分区展示原创与部分精选组件，分区按钮可打开完整列表。181 个其他示例可通过「其他」、搜索或直达链接访问，已移除 559 个组件变体与 hooks 用法示例。
- The main gallery features 144 works. All shows originals and a selection from each category, with a button to open the full category. Another 181 examples are available on demand under Other, through search, or by direct link. Removed 559 component variants and hook usage examples.

## 0.1.0

- 首次发布收录 884 个可交互示例，包括 36 个原创控件和 18 款原创加载动效。
- 图鉴提供中英文、深浅主题、筛选搜索、收藏和可分享的详情链接。加载动效可以调参并导出 HTML 或 JSX，部分原创控件提供离线独立 HTML。

- First release with 884 live examples, including 36 original controls and 18 original loaders.
- The gallery supports English and Simplified Chinese, light and dark themes, search and filters, favorites, and shareable details. Loaders can be customized and exported as HTML or JSX. Selected original controls offer standalone offline HTML.
