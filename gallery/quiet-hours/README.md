# Quiet Hours

受 Sean Galt 的 [Minimalistic Productivity UI](https://x.com/seanaiux/status/2122778549937422352) 启发。参考了四卡面板、能量统计周期、睡眠阶段的展开方式，以及专注计时和环境音的联动。

本页使用独立的排版、图表和界面素材。能量与睡眠是演示数据，环境音由 Web Audio 合成。专注预设选好后点 Start，可暂停、继续或重置。支持键盘操作与系统减少动态效果设置。

「专注轨迹」是 UI Moments 新增的功能。每轮计时结束才记入当天，彩条按时长分段，列表显示完成时间。休息显示在轨迹中，专注总时长仅累计番茄钟和深度工作。记录保存在浏览器本地。

HTML、CSS 和 JavaScript 独立实现，使用仓库的 MIT 许可证。页面无需第三方代码、图像或音频资源。
