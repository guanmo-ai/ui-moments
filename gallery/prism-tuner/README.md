# Prism Tuner

UI Moments 原创光学交互。拖动玻璃镜片，在 410–660 nm 内改变光束颜色、扇面方向和扩散范围。四个预设可以直接跳至相应波长。键盘支持方向键、Home 和 End。镜片的滑动随系统减少动态效果设置调整。光束由 Canvas 绘制，是对可见光的风格化演示。

从仓库根目录运行 `python3 -m http.server 5173`，打开 `/gallery/prism-tuner/`。共享资源为 `assets/embed.js`、`assets/fonts/Geist-latin-wght.woff2` 和 `assets/fonts/GeistMono-latin-wght.woff2`。代码采用仓库的 MIT 许可证，字体采用 SIL OFL（[Geist](../../assets/fonts/OFL-Geist.txt)、[Geist Mono](../../assets/fonts/OFL-GeistMono.txt)）。
