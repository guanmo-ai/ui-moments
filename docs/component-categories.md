# 组件分类与展示

每条记录对应一个可直接体验的 UI。加载指示器逐个列入主画廊，与开关、旋钮、滑块、导航和日期选择同级；不把一个上游库包装成合集入口，不使用封面或录屏代替实际 UI。原作者、库版本和许可证属于来源信息。

主分类依据用户操作目的，而非库名、技术栈或视觉形状：

| 分类 | 范围 | 当前映射 |
| --- | --- | --- |
| 反馈与状态 | 加载、进度、成功/失败与状态显示 | 44个加载指示器、霓虹状态反馈 |
| 选择与输入 | 选择一个值、切换或输入 | 开关、旋钮、亮度/时间/色温滑块 |
| 导航 | 在内容、页面或区域之间移动 | 标签导航 |
| 日期与时间 | 选择日期或时间 | 日历选择 |

分类参考 [Material Design 官方组件概览](https://developer.android.com/design/ui/mobile/guides/components/material-overview) 的用途划分，按现有内容合并「选择与输入」，将日期与时间单列，便于查找；这是一套适用于本图鉴的分类。不存在可用组件的分类不显示。环形、几何、圆点、线条属于加载指示器形态，是「反馈与状态」内的二级筛选。

桌面四列，中屏三列，手机两列。所有组件使用同级展示区，实际控件可直接操作，名称旁的代码/放大按钮用于后续操作。加载指示器与独立加载页复用参数和代码面板；保留第三方署名及完整 MIT 许可。旧的加载页与锚点继续可用。

接入入口：`gallery/works.js` 记录非加载组件，`assets/catalog.mjs` 合并44个加载指示器并提供用途与形态分类。新增组件须指定用途；同类实现无须新增大类。嵌入组件使用 `?embed=ui`，同源消息用于跟随主题、暂停离屏动画。未支持嵌入协议的组件可按其自身布局运行。

验证：`npm run test:site`、`npm run test:ldrs`；实际浏览器检查直接操作、分类交叉筛选、代码复制、手机和浅深主题。
