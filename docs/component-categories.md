# 组件分类与展示

每条记录对应一个可直接体验的 UI。加载指示器逐个列入主画廊，与开关、旋钮、滑块和导航同级。原作者、库版本和许可证属于来源信息。

主分类依据用户操作目的，而非库名、技术栈或视觉形状：

| 分类 | 范围 | 当前映射 |
| --- | --- | --- |
| 反馈与状态 | 加载、进度、成功/失败与状态显示 | 11 款原创加载动效、44 款 LDRS、47 款 Loading UI、46 款 SVG Spinners、12 种 Micron 点击反馈 |
| 选择与输入 | 选择一个值、切换或输入 | 昼夜开关、弹性滑尺、对齐拨片、夹页键 |
| 导航 | 在内容、页面或区域之间移动 | 当前无作品 |

分类参考 [Material Design 官方组件概览](https://developer.android.com/design/ui/mobile/guides/components/material-overview) 的用途划分，按现有内容合并「选择与输入」。画廊只显示含有组件的分类。环形、几何、圆点、线条、文字、字符、图标和状态属于加载指示器形态，是「反馈与状态」内的二级筛选。

桌面默认五列，可选四列或六列，浏览器会记住选择。平板自动使用三列，手机使用两列。实际控件可直接操作，名称旁的放大按钮打开详情。加载动效在详情内可调整、复制或下载代码，示例随实现附带对应的 MIT 许可。

画廊由 `assets/catalog.mjs` 合并 `gallery/works.js`、原创加载动效和各个上游组件目录。嵌入组件使用 `?embed=ui`，同源消息用于跟随主题、暂停离屏动画。

构建后运行 `npm test` 检查组件索引、日期逻辑、导出和上游许可。浏览器检查使用 `npm run package:site` 生成的发布目录，运行 `npm run test:browser`。
